Создать консольное приложение «Список покупок».

Каждый товар в чеке - экземпляр класса "Product"
У товаров есть следующие параметры:
10. Название продукта; [String]
20. Необходимое количество; [int]
21. Единица измерения; [String]
30. Фактическое количество; [int]
40. Цена в копейках; [int]
50. Статус необходимости к покупке; [bool]
60. Категория; [ProductGroup]

Добавить класс "ProductGroup" (категория)
